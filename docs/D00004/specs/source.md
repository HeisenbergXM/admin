# 需求来源说明 — D00004 运输管理改造 · 前端页面设计

## 来源

- 上游需求：[D00003 运输管理改造 — 按 VIN 单车维护物流信息](../../D00003/specs/design.md)
- 呈现风格参照：[D00002 前端页面设计](../../D00002/specs/design.md)

## 背景

D00003 将运输管理从「单据驱动批量流转」改为「按 VIN 单车维护」，并保留旧单据式功能（仅隐藏入口）。本 spec 是给**前端开发**使用的文字版页面设计，针对 D00003 的变更，产出每个功能页面的详细描述（布局线框、字段清单、交互与流转），保证前端可照此实现。

## 目标

1. 为 D00003 新增的两段按 VIN 物流功能给出页面级落地说明：
   - 车厂 → 中转仓库（按 VIN 单车维护入库）：待办列表 + 入库表单
   - 中转仓库 → 经销商（按 VIN 单车维护配送）：待办列表 + 配送表单
2. 说明运输管理导航/菜单的变化：新页面成为唯一入口，旧单据式页面隐藏。
3. 复用 D00002 已确立的全局交互范式（草稿→确认锁定→三态、卡控禁用、状态徽标、列表通用规范），不重复推导。

## 范围与决策（已与用户确认）

| 决策点 | 结论 |
|--------|------|
| 文档范围 | **仅运输管理模块**页面变更；生产/销售/财务/全景等其余模块页面引用 D00002，不重复 |
| 交互形态 | **独立表单页**：待办列表点「维护」跳转独立表单页填写并确认（与 D00002 各阶段表单一致） |
| 呈现风格 | 沿用 D00002：ASCII 线框 + 字段表 + 流转说明 |
| 旧页面处理 | 旧运输页面（运输单、发车清单三层）从菜单隐藏、页面代码保留（对应 D00003 §8 停用不删除） |
| trolly_type/fully_load | 保留为配送表单可选字段（D00003 已确认保留） |

## 非目标

- 不涉及生产/销售/财务/上牌/主数据/系统管理/全景视图的页面重绘（沿用 D00002）。
- 不定义高保真视觉稿、组件库选型、具体像素（由前端按 D00002 既定风格实现）。
- 不重复 D00003 的数据模型/卡控推导（以 D00003 为准）。
